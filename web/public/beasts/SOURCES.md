# Beast artwork sources

Backdrop images for the beast scenes (tứ tượng and hung thú). All are public domain or CC0, so no attribution is required;
the sources are listed for traceability. Every file was recoloured, cropped, background-keyed and re-encoded as WebP
(see `Reader/web/src/components/BeastPortraits.tsx` for how the colours are applied in CSS).
